Ayuda

Maprayés es un sistema de codificación único. Aquí tienes algunas instrucciones:

  • Usa el Traductor para convertir texto a Maprayés y viceversa.
  • Consulta la Tabla de Códigos para ver todos los símbolos y agregar favoritos.
  • Practica con la Práctica Libre o aprende con el Modo Aprendizaje.
  • Personaliza tu experiencia en Configuración.
  • Genera un código QR en el traductor para compartir tu código Maprayés.
